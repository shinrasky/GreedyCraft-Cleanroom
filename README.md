# GreedyCraft-Cleanroom

This project aims to migrate the GreedyCraft Modpack, originally based on the Forge loader, to Cleanroom.

If you have any questions, you can join the QQ group: 1126031322.

The project currently depends on Cleanroom version 0.6.6.

Original ModPack: GreedyCraft (https://github.com/TCreopargh/GreedyCraft)
