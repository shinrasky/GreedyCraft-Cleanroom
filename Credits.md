# Credits

## Shaderpacks

ComplementaryShaders by Emin (https://www.curseforge.com/minecraft/customization/complementary-shaders)

Permission is granted by shaderpack author

If you have problems related to this shader, join their discord channel: https://discord.gg/A6faFYt

The default shader settings are mostly default because the shader pack author requested it. The default settings are more realistic, but if you prefer a warmer and more  vibrant look, you can use the alternative shader options in /shaderpacks. Simply clear the default file, then paste the alternative content to the default file and restart the game.
